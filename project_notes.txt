== Mission 2: The apprentice moves (Requirement 2) ==
- Player (Game scene), position (0,0,0). Components:
    - SpriteRenderer: wizzard_f_idle_anim_f0
    - Rigidbody2D: Dynamic, Gravity Scale 0, Freeze Rotation Z
    - BoxCollider2D: size 0.8 x 0.4, offset (0, -0.675), feet only (top-down: feet decide where a character stands)
    - PlayerInput: Actions = PlayerControls, Default Map = Player, Behavior = Send Messages
    - PlayerMovement (script)
- Assets/Input/PlayerControls.inputactions:
    - Action map "Player" > action "Move" (Value, Vector2)
    - Bindings: WASD and arrow keys (2D Vector composites, Digital Normalized)
- Assets/Scripts/PlayerMovement.cs:
    - [RequireComponent(typeof(Rigidbody2D))]
    - [SerializeField] private float speed = 4
    - Awake: caches Rigidbody2D with GetComponent
    - OnMove(InputValue): stores the Vector2 input (called by PlayerInput via Send Messages)
    - FixedUpdate: rb.linearVelocity = moveInput * speed (velocity = units per second, so no Time.deltaTime)

== Mission 4: Spell bolts (Requirement 4) — in progress ==
- Arts/BoltCircle: Unity built-in circle sprite (placeholder bolt art)
- Prefabs/SpellBolt: SpriteRenderer (color #B07CFF, scale 0.35, Order in Layer 3),
  Rigidbody2D (Dynamic, Gravity 0, Collision Detection Continuous),
  CircleCollider2D (Is Trigger), SpellBolt.cs
- SpellBolt.cs: [RequireComponent(Rigidbody2D)]; speed 5, lifetime 3 (serialized);
  OnEnable resets timer + sets linearVelocity = transform.right * speed (launch per reuse);
  Update counts down with Time.deltaTime, SetActive(false) when done (no Destroy);
  OnDisable zeroes velocity
- BoltPool (GameObject at 0,0,0) + BoltPool.cs: List<GameObject> bolts; Awake instantiates
  poolSize (20) bolts as children, inactive; GetBolt(position, rotation) finds first inactive,
  sets position/rotation BEFORE SetActive(true) (OnEnable launches using current rotation), returns it
- Verified: Play shows 20 inactive SpellBolt(Clone) children under BoltPool
- Debugging note: a stray Rigidbody2D on Grid made the whole hall fall; found via
  Rigidbody2D Info > Contacts; removed before commit

  Mission 4 - Statues and pooled spell bolts
- SpellBolt prefab: circle sprite tinted #B07CFF, scale 0.35, Order in Layer 3, Rigidbody2D (Dynamic, gravity 0, Collision Detection Continuous), CircleCollider2D set to trigger
- SpellBolt.cs: OnEnable sets velocity along transform.right and resets a lifetime timer; Update counts the timer down and deactivates the bolt after 3 s; OnDisable zeroes velocity
- BoltPool.cs: creates 20 inactive bolts in Awake as children of the pool; GetBolt returns the first inactive one and sets position and rotation before SetActive(true), because OnEnable launches the bolt; if all are busy it creates a new bolt (pool grows)
- Why pooling: avoids Instantiate/Destroy every shot, which causes garbage collection and frame hitches
- StatueCaster.cs: countdown timer with a start delay and fire interval; asks BoltPool for a bolt at its FirePoint
- FirePoint child carries the aim (rotation Z) so the statue sprite stays upright
- 4 statues (Top_Left, Top_Right, Left, Right) from one Statue prefab; FirePoint rotations -90 / -90 / 0 / 180; staggered start delays 1 / 1.75 / 1.4 / 2.1 so they don't fire on the same beat
- Bug found: a Rigidbody2D accidentally added to Grid made the whole hall fall; found using Rigidbody2D Info > Contacts; removed
- Bug found: all statues fired left because FirePoint rotation 180 was applied to the prefab; fixed by setting each FirePoint's rotation as a per-instance override in the Hierarchy
- Git: stopped tracking Unity-generated .csproj files and added *.csproj to .gitignore

Mission 5 - Collisions (R5)
- Bolt layer; Bolt x Bolt unchecked in the Physics 2D Layer Collision Matrix so bolts pass through each other
- SpellBolt.cs: OnTriggerEnter2D deactivates the bolt (returns it to the pool) when it touches a wall or the wizard
- SpellBolt prefab tagged "Bolt"
- PlayerHit.cs on the Player: OnTriggerEnter2D checks CompareTag("Bolt") and calls TrialManager.EndTrial()
- Why the player detects the hit: the bolt is a prefab and can't reference the scene's TrialManager; the Player can, via a SerializeField slot
- TrialManager.cs: EndTrial sets Time.timeScale = 0 to freeze the game; a trialOver bool stops it running twice; OnDestroy resets timeScale to 1 so the next scene isn't frozen

Mission 6 - Timer and fail screen
- Canvas (Screen Space - Overlay, Canvas Scaler: Scale With Screen Size 1920x1080, match 0.5) so UI keeps its size in any window
- TimerText (TextMeshPro) at top center; TrialManager adds Time.deltaTime each frame and shows it with ToString("F1")
- FailPanel (dark, hidden by default) with "Trial Failed", "You lasted X s" and a Retry button
- EndTrial freezes time, writes the result and shows the panel
- Retry reloads the active scene; OnDestroy resets Time.timeScale so the reloaded scene isn't frozen
- Learned: the Scene view draws an Overlay canvas at 1 pixel = 1 unit, so judge UI in the Game view
